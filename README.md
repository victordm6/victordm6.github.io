# Victor & Maria Eduarda — Álbum

Álbum interativo em 3D hospedado em https://victordm6.github.io/.

## Arquivos

- `index.html`: entrada do site.
- `viewer/entry.js`: inicialização do álbum.
- `data/`: conteúdo, textos e estado inicial.
- `_next/`: módulos e estilos usados pelo visualizador.
- `assets/` e `sounds/`: imagens, fontes e áudio utilizados pelo álbum.
- `replica-runtime.js`: serviços locais e armazenamento no navegador.
- `.nojekyll`: permite que o GitHub Pages sirva o diretório `_next`.

O GitHub Pages publica a raiz da branch `main`. Fotos adicionadas e alterações de destinos ficam no navegador. Música e mapas dependem dos respectivos serviços externos.

O conteúdo e a interface do álbum são usados com autorização expressa do solicitante.
